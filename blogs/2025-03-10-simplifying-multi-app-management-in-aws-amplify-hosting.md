AWS Amplify Hosting has now made it possible to connect many more Amplify apps to a single repository. This change improves the way developers can integrate with Git providers which is especially beneficial for monorepo architectures. Amplify now uses a single webhook per repository for all associated apps, streamlining the development workflow.
